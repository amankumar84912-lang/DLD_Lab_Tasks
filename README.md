# DLD Lab Tasks

This repository contains Digital Logic Design lab experiments saved as LabVIEW Virtual Instrument (.vi) files, together with wiring screenshots for the experiments.

## Folder contents

- **DLD Lab/** — the LabVIEW experiment files and the Wairing ScreenShot folder.
- **Wairing ScreenShot/** — screenshots matched to the corresponding experiment files below.

Open a .vi file in LabVIEW to view or run the circuit demonstration. A compatible LabVIEW installation is required; file compatibility can depend on the LabVIEW version.
